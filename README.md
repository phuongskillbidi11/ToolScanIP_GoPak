# ToolScanIP

ARP-based network scanner with terminal UI, web dashboard, and nginx reverse-proxy.
Built in C for Linux / Raspberry Pi. Designed for factory/IoT environments running Luckfox devices.

**Author:** I-Soft Tran Hoang Phuong — Embedded IIoT

---

## Quick start

```bash
make                              # build native binary
sudo ./build/ipscanner -i eth0    # terminal scan
sudo ./build/ipscanner -i eth0 -w 8080  # web dashboard
```

On Raspberry Pi:
```bash
make deploy                       # cross-compile + upload
ssh admin@100.66.44.107
cd ~/ToolScanIP && sudo ./gen-nginx.sh   # start everything
```

## Skill system

Detailed documentation is split into focused skills. Load the manifest to see what is available,
then load individual skills on demand.

**Manifest:** [`skills/manifest.json`](skills/manifest.json)

| Skill | What it covers |
|-------|---------------|
| [`build`](skills/build/SKILL.md) | Compile, cross-compile, xxd HTML embedding |
| [`deploy-pi`](skills/deploy-pi/SKILL.md) | SCP deploy, gen-nginx.sh, Pi setup |
| [`web-ui`](skills/web-ui/SKILL.md) | Edit dashboard, HTTP routes, JSON API |
| [`comments`](skills/comments/SKILL.md) | Host labels, MAC vs IP keys, auto-login rule |
| [`probe`](skills/probe/SKILL.md) | SSH/HTTP/mDNS probes, adding new probe types |
| [`arp-scan`](skills/arp-scan/SKILL.md) | Raw ARP engine, parallel resolver, OUI lookup |
| [`nginx-proxy`](skills/nginx-proxy/SKILL.md) | Port mapping, reverse proxy, /regen route |

### Load a skill from terminal

```bash
./scripts/load_skill.sh list          # list all skills
./scripts/load_skill.sh build         # print build instructions
./scripts/load_skill.sh nginx-proxy   # print nginx proxy instructions
```

### For AI agents

Read `skills/manifest.json` first to understand scope.
Then load only the `SKILL.md` file for the area you are working in.
Never edit `src/scanner_html.h` — it is auto-generated by `make`.
